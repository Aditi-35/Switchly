# Switchly

**A multi-tenant feature flag platform.**

Switchly is a learning project developed as part of a course on AI-first software engineering. The goal is to build a platform that allows applications to turn features on or off remotely without redeploying their code.

A feature flag separates deploying code from releasing a feature.

## Project Goals

Switchly aims to support:

- **Feature flags** — Enable or disable features remotely.
- **Dynamic configuration** — Change configuration values without redeploying applications.
- **Targeting and rollouts** — Control which users receive a feature.
- **Multi-tenancy** — Keep different organizations and their projects isolated.
- **Authentication and API keys** — Support secure access for users and applications.
- **Client SDK** — Allow applications to evaluate feature flags.
- **AI-assisted features** — Explore creating and searching flags using natural language.

## Tech Stack

- **Backend:** Java and Spring Boot
- **Build tool:** Maven

Additional technologies will be documented as they are introduced and integrated into the project.
